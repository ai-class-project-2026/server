## 코드 구조

채팅 메시지 하나가 들어오면 이렇게 처리돼요.

```
채팅 POST (routers/chat.py:92)  또는  POST /moderate (routers/ai.py)
   └→ moderation.moderate(text, context, level)        ← __init__.py
        ① normalize.normalize(text) → (정규화된 글자, index_map)
        ② dict_filter.find(norm)   → 욕설 사전에 걸리고 화이트리스트에 없는 위치
             걸리면 → 욕설 확정 (score 1.0), 원문 위치(spans)를 계산해서 가림
        ③ 안 걸리면 → classifier.score()   (KcELECTRA ONNX 모델, 경로 설정이 없으면 건너뜀)
             score ≥ 기준값이면 욕설 (filter_level 1/2/3 → 0.9/0.7/0.5)
```

| 파일 | 하는 일 | 지금 상태 |
|---|---|---|
| `backend/app/moderation/normalize.py` | 우회 표기를 되돌리는 8단계: 전각 문자 정리 → 숫자/영문을 모음으로(ㅅ1 → ㅅㅣ) → 영문 자판(tlqkf → 시발) → 기호 제거 → 공백 정리 → 끼워 넣은 숫자 제거 → 자모 합치기 → 늘이기 축약 | **거의 완성** |

## 버그: 주석 안의 단어가 욕설 목록에 들어가요

`dict_filter.py`의 `_load`는 파일 내용을 `split()`으로 공백마다 자르고, `#`으로 **시작하는 조각만** 빼요. 그래서 `# one word per line, normalized form (part 3 grows this)` 같은 주석 줄에서 `one`, `word`, `3`, `the`, `model`, `새끼`... 같은 조각이 전부 욕설 단어로 들어가요. 직접 넣어 본 결과예요.

```
"3시에 만나"          → 욕설로 판정 ❌
"새끼 고양이 귀엽다"  → 욕설로 판정 ❌  (주석에서 "건너뛰라"고 적은 바로 그 예시)
"the model is good"   → 욕설로 판정 ❌
"ㅅ1발"               → spans가 [[0,3],[0,3]]로 두 번 나옴 ("# 시발" 주석 때문에 "시발"이 중복으로 들어감)
```

whitelist.txt도 같은 문제로 `a`, `bad`, `word` 같은 조각이 들어가 있어요. 해결은 줄 단위로 읽고 `#`으로 시작하는 줄을 통째로 버리면 돼요. `_load`를 아래처럼 바꾸면 되는데, 원하면 제가 고쳐 드릴게요.

```python
_load = lambda name: [
    l.strip() for l in (_here / name).read_text(encoding="utf-8").splitlines()
    if l.strip() and not l.lstrip().startswith("#")
]
```

이걸 고치기 전/후 score.py 결과를 붙이면 첫 PR로 딱 좋아요.

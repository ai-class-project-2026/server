# AI 페르소나 역할극

**사람이 한 대화가 아니다.** 2026-11-25에 Claude가 카드의 역할마다 말투를 정해 혼자 연기했다.

| 파일 | 내용 |
|---|---|
| `pilot_unlabeled.jsonl` | 파일럿 카드 P001~P020의 대화 20개 |
| `hard_unlabeled.jsonl` | 약점 카드 H001~H024의 대화 24개 |

* 모든 줄에 `"source": "ai_persona"`가 있다
* 정답(`events`)은 비어 있다. AI가 달지 않았다
* 쓰는 곳: 라벨러 두 명이 기준을 맞춰 보는 연습, 평가 도구 점검. 채점한다면 "AI 역할극, 사람 테스트셋 아님"이라고 같이 적는다
* 쓰지 않는 곳: `test.jsonl`, `pilot.jsonl`, `hard.jsonl`, 발표의 최종 점수, 학습 데이터
* 한 사람(AI)이 모든 역할을 알고 썼다. 그래서 실제 단톡보다 답이 빠르고 맞춤법이 고르고 흐름이 카드대로 깔끔하다. 사람 대화보다 쉬울 수 있다
* 시각(`ts`)이 없다. 모든 말은 `ref_datetime`에 한 것으로 계산된다

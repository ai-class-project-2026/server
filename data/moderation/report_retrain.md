## 1. 한눈에 보기

```
[욕설 아님]/[욕설 신고] → ① 모으기 → ② 꺼내기 → ③ 익명화 → ④ 검수(2명)
   → ⑤ 학습 데이터에 넣기 → ⑥ 재학습 → ⑦ A~D셋 재평가 → ⑧ 좋아졌을 때만 배포 → ⑨ 기록
                         └→ (같은 표현이 반복되면) 사전 바로 고치기 (3장)
```

## 2. 단계별로

### ① 모으기
사용자가 가려진 메시지에서 [욕설 아님]을 누르면 `false_positive`, 안 가려진 메시지에서 [욕설 신고]를 누르면 `missed`가 저장돼요. 지금 동작하는 그대로예요.

### ② 꺼내기 (재학습 전, 또는 주 1회)
```sh
uv run python eval/moderation/export_reports.py --db app.db --out data/moderation/reports/2026-11-26.jsonl
```
- `reports`와 `messages`를 합쳐서 신고된 메시지 하나에 한 줄씩 꺼내요. 담는 것:
  - 메시지 원문 (익명화한 것)
  - 같은 채널의 앞 메시지 최대 3개
  - 신고 종류별 신고한 사람 수 (`false_positive`, `missed`)
  - 당시 판정(`is_profane`, `profanity_score`, `model_version`)
- 저장 위치 `data/moderation/reports/`는 `.gitignore`에 있어서 **git에 올라가지 않아요** (실제 사용자 대화).
- **AI 분석에 동의한 워크스페이스(`ai_enabled_at`이 있는 곳)의 메시지만** 꺼내요 (기획서 11장).
  신고 데이터 사용 동의를 따로 정하면(4장) 스크립트의 이 조건을 바꿔요. 결정 전에는 실제 DB에서 꺼내지 않아요.

### ③ 익명화
- 꺼낼 때 자동으로: 워크스페이스 멤버 이름(두 글자 이상)과 @멘션 → `[이름]`, 이메일 → `[이메일]`, 전화번호 → `[번호]`.
- 검수자가 손으로: 학교, 주소 같은 장소 → `[장소]`, 자동으로 못 잡은 별명.
- `user_id`, `channel_id`는 내보내지 않고, 신고한 사람 수만 남겨요.
- 욕 판정에 필요한 글자(욕, 우회 철자)는 지우지 않아요.

### ④ 검수 (2명이 따로)
- 기준은 기획서 9.8과 인수인계 문서 1.4의 표예요 (테스트셋 C/D와 같은 기준).
- 결과는 `1`(욕), `0`(정상), `보류` 중 하나예요. `보류`는 비꼼·암시처럼 복원할 욕이 없는 경우이고, 자동 판정에서 빼요 (9.8).
- 두 사람이 다르게 달면 이야기해서 정하고, 그래도 다르면 넣지 않아요.
- **테스트셋(A~D) 문장과 같거나 거의 같은 문장은 넣지 않아요** (17.8 규칙 6).
  똑같은 문장(정규화해서 같은 것 포함)은 `build_train.py`가 자동으로 빼요. **앞 메시지에 테스트셋 문장이 들어 있어도 그 줄을 통째로 빼요.**
  검수자는 "거의 같은" 문장만 보면 돼요.
- 꺼낸 파일의 `label`, `reviewers`, `reason` 칸을 채워요. 한 줄 예:
  `{"message_id": 3, "text": "...", "context": ["..."], "false_positive": 2, "missed": 0, ..., "label": 0, "reviewers": ["A", "B"], "reason": "동물 새끼"}`

### ⑤ 학습 데이터에 넣기
```sh
uv run python eval/moderation/export_reports.py --to-raw data/moderation/reports/2026-11-26.jsonl \
    --out data/moderation/raw/reports_20261126.jsonl
```
- `label`이 0이나 1이고 검수자가 2명 이상인 줄만 `{"text", "label", "context"}`로 넘겨요. `raw/`는 git에 올리지 않아요.
- `build_train.py`가 `raw/`의 파일을 자동으로 읽고 증강도 해요. 코드는 바꿀 필요가 없어요.
- 공개 데이터 라벨이 틀렸던 게 신고로 드러나면 원문을 고치지 말고 `--fixes`(라벨 고침 파일)로 바꿔요.
- 학습에 쓰면 안 되는 문장이 더 있으면(예: 발표 시연 문장) `--hold-out` 파일에 넣어서 빼요.
- 몇 건을 넣었는지(욕/정상)는 PR에 적어요.

### ⑥ 재학습 (파트 1)
- `train.py`를 지난번과 같은 `--seed`, `--val-groups`로 돌려요. 그래야 점수 차이가 신고 데이터 때문인지 알 수 있어요.

### ⑦ 재평가
- **지난번과 같은 A~D셋**으로 `score.py`를 돌려서 `eval/reports/moderation.csv`에 새 버전 줄을 남겨요.

### ⑧ 배포 조건 ("성능이 오른 경우에만")
아래를 모두 만족할 때만 서버의 모델을 바꿔요.
- C셋 F1이 떨어지지 않음
- D셋 오탐률이 3% 이하이고, 지난 버전보다 높아지지 않음
- A셋 F1이 1%p 넘게 떨어지지 않음
- 응답 시간이 100ms 이내

하나라도 못 지키면 이전 모델을 그대로 써요.

### ⑨ 기록
`moderation.csv`의 버전 이름에 날짜와 추가한 신고 건수를 같이 적어요. 예: `v4-reports-1203 (+42)`

## 3. 빠른 길: 사전 바로 고치기
같은 표현에 오탐 신고가 반복되면 재학습을 기다리지 않고 사전을 고쳐요.
- 멀쩡한 뜻이 분명한 표현(예: `첫차 시발`)은 `whitelist.txt`에 넣어요.
- 확실 목록에 있던 말이 멀쩡하게도 쓰이면 애매 목록(`badwords_ambiguous.txt`)으로 옮겨요.
- 미탐 신고가 반복되는 표현(예: `ㅈ같네`)은 확실 목록에 넣어요.
- 고친 뒤 `score.py`로 C, D셋 전후 점수를 PR에 적어요.

## 6. 시험 기록 (2026-11-26, 인수인계 3-4 끝 기준)

임시 DB(새로 만든 SQLite, 실제 `app.db` 아님)에서 테스트 계정 2개로 했어요. 모델 없이(사전만) 돌렸어요.

**① 모으기**: 워크스페이스(AI 분석 동의, 필터 3단계)에서 메시지 9개를 보내고 신고 5건을 넣었어요.

| 메시지 | 판정 | 신고 |
|---|---|---|
| 고양이 새끼가 너무 귀여워 | 가림 | 욕설 아님 (2명) |
| 우리 할머니댁 수박 씨 발아율 좋대 | 가림 | 욕설 아님 |
| 개같이 착하네 우리 강아지 | 가림 | 욕설 아님 |
| 아 ㅈ같네 숙제 너무 많아 | 통과 | 욕설 신고 |
| 엿이나 먹어라 진짜 | 통과 | 욕설 신고 |

- 같은 사람이 같은 신고를 다시 보내면 새로 저장하지 않고 기존 신고를 돌려줬어요.
- 다른 사람이 같은 메시지를 신고하면 꺼낼 때 신고 수가 2로 나와요.

**② 꺼내기, ③ 익명화**: 5줄이 나왔고 앞 메시지 3개가 같이 들어갔어요. 앞 메시지 속 멤버 이름은 `[이름]`으로 바뀌었어요.
따로 확인한 것: `010-1234-5678` → `[번호]`, 이메일 → `[이메일]`, `@이름` → `[이름]`. 욕(`ㅅ1발`)과 날짜는 그대로예요.

**④ 검수** (기준 9.8. 두 번째 검수자는 시험이라 정하지 않았어요)

| 메시지 | 라벨 | 이유 |
|---|---|---|
| 고양이 새끼가 너무 귀여워 | 0 | 동물 새끼 |
| 우리 할머니댁 수박 씨 발아율 좋대 | 0 | "씨 + 발아율"을 붙여 읽어서 생긴 씨발 |
| 개같이 착하네 우리 강아지 | **1** | "개같이"는 칭찬 앞의 강조어로 써도 욕 (9.8 강조어 기준). 신고는 틀린 것 |
| 아 ㅈ같네 숙제 너무 많아 | 1 | 초성으로 쓴 ㅈ같다 |
| 엿이나 먹어라 진짜 | 1 | 엿 먹어라 |

**⑤ 학습 데이터에 넣기**: `--to-raw`로 5줄을 `raw/`에 넣고 `build_train.py --out (임시 경로)`를 돌렸어요.
- 들어간 것: "아 ㅈ같네…", "엿이나 먹어라…" (각각 원문 1줄 + 증강 3줄)
- 빠진 것 3줄: "고양이 새끼가 너무 귀여워"가 D셋 초안에 있는 문장이라 빠졌고, 나머지 두 줄은 앞 메시지에 이 문장이 있어서 같이 빠졌어요. 테스트셋이 학습에 새지 않게 막는 장치가 동작한 거예요.
- 확인한 뒤 `raw/`에서 시험 파일을 지웠어요. 재학습(⑥)은 하지 않았어요.

**알게 된 것**
- 신고 화면에서 "욕설 아님"이 와도 검수하면 욕일 수 있어요 ("개같이 착하네"). 그래서 신고를 그대로 라벨로 쓰지 않고 꼭 검수해요.
- 지금 사전이 놓치는 표현: `ㅈ같네`, `엿이나 먹어라`. 3장(빠른 길)으로 사전에 넣을 후보예요.
- 시연 중에 테스트셋 문장을 채팅에 치면, 그 뒤 메시지들의 신고는 학습에 못 써요 (앞 메시지에 테스트 문장이 남아서).
